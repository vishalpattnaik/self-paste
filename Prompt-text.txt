We are abandoning the Interactive REPL CLI and converting this project purely into a Maven Plugin. 

Please modify the main Spring Boot application class (the one annotated with `@SpringBootApplication`):
1. Remove the `CommandLineRunner` interface implementation.
2. Delete the `run(String... args)` method entirely, including the `while(true)` loop and the `Scanner(System.in)`.
3. The class should now just be a standard, empty Spring Boot entry point containing only `public static void main(String[] args) { SpringApplication.run(...); }`.
