@workspace Create a new `@Service` class named `SecurityPipelineOrchestrator`. This class will replace the AI agent and orchestrate the entire scan sequentially.

Create a public method: `public void runPipeline(String targetProjectPath)`.
Implement this exact sequence inside the method:
1. Construct the paths for the target: `nexus.json` and `pom.xml` based on the `targetProjectPath` argument.
2. Call the existing service to parse the `nexus.json` file to get the list of CVEs.
3. **THE DIRECT DEPENDENCY FILTER:** Parse the target's `pom.xml` `<dependencies>` block into a List. Filter the CVE list: Keep ONLY vulnerabilities where the `groupId` and `artifactId` explicitly exist in the target's `pom.xml`. Ignore all deep transitives.
4. Loop through the filtered direct CVEs. For those without recipes, call the Auto-Bump service sequentially.
5. For those with CSV recipes, execute the OpenRewrite service.
6. Finally, execute the Excel generation service to output the report to the `targetProjectPath`.
Include proper `log.info` and `log.error` statements for each step so the user can see the progress in the terminal.
