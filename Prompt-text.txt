@workspace The `autoBumpDependencies` method is returning a false positive. It currently trusts the Maven process `exit=0` code to assume a dependency was bumped, but the versions plugin returns 0 even when no updates are made.

Update the `autoBumpDependencies` logic with these rules:
1. Before executing the Maven versions plugin for a specific coordinate, read the target `pom.xml` file into a String or capture its Last-Modified timestamp.
2. Run the Maven process.
3. After the process finishes (even if exit=0), re-read the `pom.xml` file.
4. If the file contents (or timestamp) are EXACTLY the same, the bump FAILED (no update was available). Do NOT add this dependency to the "successfully bumped" list.
5. Only return the coordinates in the success payload if the `pom.xml` was actually modified.
