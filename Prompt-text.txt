### Section 1: Autonomous Minor Upgrades
1. **Pass ALL Dependencies to the Tool:** You MUST execute the `autoBumpDependencies` MCP tool for ALL identified vulnerable dependencies, regardless of whether they are Direct or Transitive.
2. **Trust the Java Gatekeeper:** The `autoBumpDependencies` tool contains internal heuristic gatekeeper logic. It will automatically reject major frameworks (like Spring or Tomcat) and safely inject standalone utilities into `<dependencyManagement>`.
3. **Handle the Tool Response:** - If the tool returns a "Success" payload (the POM was modified), place the dependency in the "Autonomously Upgraded" table.
   - If the tool returns a "Failed" or "Skipped" payload (blocked by the gatekeeper), place the dependency in the "Requires Manual Review" table.
