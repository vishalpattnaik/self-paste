@workspace Look at my MCP tool implementations (`scanSbomFile`, `autoBumpDependencies`, etc.). 
Goal: Prevent the SSE stream termination caused by heavy payloads, unescaped characters, or raw terminal dumps returning across the JSON-RPC channel.

Rules:
1. Ensure all tool method return values are explicitly serialized using a Jackson/Gson `ObjectMapper` instead of manual JSON string concatenation. This ensures backslashes, quotes, and newlines in CVE descriptions or file paths are properly escaped.
2. For any tool capturing or executing shell commands (like Maven commands or dependency bumps), DO NOT return the entire raw stdout/stderr log across the stream. 
3. Intercept the terminal streams and filter/truncate them. Only return a clean structured summary (e.g., a List of mutated coordinates, or the last 20 lines of a stack trace if an error occurs).
4. If a tool return payload is extremely large, optimize or truncate the text fields to keep the total payload small enough to prevent an HTTP 400 Bad Request on the `/sse` endpoint.
